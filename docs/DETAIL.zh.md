# 删除对话片段

删除 DeepSeek Harness 会话中的某一轮。被删掉的那一轮不会进入**新**会话，新会话
保留它前后的对话：

- **只删除这一轮**：保留这一轮之前和之后的内容；
- **删除这一轮及之后**：只保留这一轮之前的内容。

这是「**发错会话**」的解法：从发错的那一轮切掉，在删减后的会话里继续——前面的
上下文保留，误发的那轮不会再进入模型历史，原会话自动归档（可在归档里恢复）。

原会话永远不会被修改：DSH 的会话日志是只追加的，插件用保留的事件派生一个新会话，
通过 agent factory 创建它（持久化写入、进入 SessionStore、广播、写投影缓存、
准备空闲 Agent 并挂进工作区）。

## 显示位置

每一轮对话的底部都会多一个 **删除对话** 按钮。点开后是两种删除方式和一个取消
按钮。Host 创建完成后，新会话会自动打开。

## 要求

- 启用 Chat 界面的 Web 或 Desktop 版 DSH（按钮位于
  `conversation.chat.turnTail` slot）。
- 需要已完成的轮次；正在运行的会话会等到这一轮结束才能删。

## 限制

- 只能按整轮删除，不能删单条消息或工具调用。
- 分支会话（或截断产生的新会话）不能做「只删除这一轮」，只能用截断模式。
- 新会话是新的 Session id，标题会加编号（`标题 (1)`）。不需要原会话时可以
  在归档里保留或取消归档。
- 描述被删轮次的压缩检查点和标题引用会随该轮一起丢弃。
